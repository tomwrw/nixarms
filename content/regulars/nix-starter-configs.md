Minimal and standard flake templates with heavy comments, designed to be the thing you copy on day one.

<!--more-->

There are two templates: **minimal**, which is a single flake with one host and one user, and **standard**, which adds the folder structure most bigger configs grow into. Start with minimal. The comments explain each line, so you learn the layout while you set up your machine.
